# 📸 Nathalie_mota — Site WordPress pour Photographe

## Description

Nathalie Mota est un site WordPress développé sur mesure pour une photographe professionnelle spécialisée dans l’événementiel. Le projet a été conçu à partir de maquettes fournies et intègre une galerie dynamique permettant aux visiteurs de consulter, filtrer et découvrir les différentes photographies.

L’objectif principal était de créer un site performant, moderne et administrable facilement via le back-office WordPress.

## Fonctionnalités principales

* Galerie photo dynamique.
* Filtres par catégorie, format et date.
* Chargement des photos en AJAX sans rechargement de page.
* Page détail pour chaque photographie.
* Lightbox pour l’affichage des images en plein écran.
* Formulaire de contact relié aux photos.
* Interface responsive (mobile, tablette, desktop).
* Gestion des contenus via WordPress et ACF.

## Technologies utilisées

## Installation

1. Thème Wordpress personnalisé
2. Importer la base de données WordPress.
3. Configurer le fichier `wp-config.php`.
4. Installer les dépendances nécessaires (extensions et plugins).
5. Lancer le projet sur un serveur local (XAMPP).
